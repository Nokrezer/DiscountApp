# Discounter

Discounter is a mobile app for storing your loyalty and discount cards in one place. Add a card by scanning it or entering its details manually, then customize it so it’s easy to find.

## Features

- Add cards by scanning them or entering their details manually.
- Customize each card with a name and color.
- Set a card logo using the retailer’s website domain.
- Edit or delete saved cards.

## Quick Start

Run these commands from the root of the repository:

```bash
npx expo install
npx expo start
```

Open Expo Go on your phone and scan the QR code shown in the terminal.

## Build an Android APK

Run these commands from the root of the repository:

```bash
npx expo prebuild --platform android
cd android
./gradlew assembleRelease
```
